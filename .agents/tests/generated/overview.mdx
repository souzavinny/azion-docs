**Data Stream** is an Observe product that feeds stream processing, SIEM, and big data platforms with your event logs in real time. Logs use ASCII encoding to avoid parser issues.

Use Data Stream to:

- Collect, group, and transmit raw logs to a destination that you choose.
- Choose the Azion products and domains to collect logs from.
- Choose the variables that the stream uses.

## Data sources

The selection of a data source is mandatory. Data Stream collects event logs from:

- Activity History
- Applications
- Functions
- WAF Events

## Templates

Data Stream provides these templates:

- Activity History Collector
- Applications + WAF Event Collector
- Functions Event Collector
- WAF Event Collector
- Custom Template

## Connectors

A connector defines the destination that receives your logs. Data Stream transmits logs to these connectors:

- Apache Kafka
- AWS Kinesis Data Firehose
- Azure Blob Storage
- Azure Monitor
- Datadog
- Elasticsearch
- Google BigQuery
- IBM QRadar
- S3 - Simple Storage Service
- Splunk
- Standard HTTP/HTTPS POST

## Domain association

You can associate domains with a stream through the **Filter Domains** or **All Domains** options. Domain association also includes a **Sampling (%)** field. Sampling is limited to one active stream and is not available on all account plans.

## Customizable payload

The **Standard HTTP/HTTPS POST** connector accepts a customizable payload. You can configure the **Max Size**, the **Log Line Separator**, and the **Payload Format**. **Max Size** is in bytes and accepts values from 1000000. Azion recommends NDJSON, with `\n` as the log line separator and `$dataset` as the payload format.

## Endpoint health monitoring

Data Stream monitors the health of the endpoint once a minute. The monitoring returns HTTP `504` on a timeout and HTTP `503` when the endpoint is unavailable. The timeout for HTTP POST endpoints is 20 seconds.

---

## Limits

Data Stream has these limits:

| Limit | Value |
| --- | --- |
| Sending interval | Every 60 seconds or 2,000 requests, whichever happens first |
| Sending interval for AWS Kinesis Data Firehose | Every 60 seconds or 500 requests, whichever happens first |
| Data transfer to the destination | Up to 3 minutes |
