This guide instructs you through the deployment of your first application from a template. The guide has three stages:

- Choose a template in Azion Console.
- Configure and deploy the application.
- Verify that the application answers on its Azion domain.

---

## Prerequisites

- An [Azion account](https://console.azion.com/).
- A GitHub account, for templates that integrate with GitHub.

---

## 1. Choose a template

To choose a template:

1. Access [Azion Console](https://console.azion.com/) > **+ Create**.
2. In the modal, select the **Templates** option.
3. Browse the templates and choose one.

The configuration page for the template opens.

## 2. Configure and deploy the application

To configure and deploy the application:

1. On the configuration page, enter the information to configure the application.
2. If the template integrates with GitHub, select **Connect with GitHub**.
3. Select **Deploy**.

During the deployment, a window shows the deployment logs. On completion, the page shows the application name, the deployment logs, and the **Azion domain**.

## 3. Verify the deployment

Azion generates the application's domain in the format `xxxxxxxxxx.map.azionedge.net/`. You cannot modify this domain.

To verify the deployment, open the application's domain in the browser.

The application answers on its Azion domain. The URL can take a few minutes to activate after the deployment. On an error right after the deployment, wait and retry before you diagnose the error.
