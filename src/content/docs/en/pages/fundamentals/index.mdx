Azion is a distributed serverless infrastructure where you host your [compatible applications](/en/documentation/get-started/frameworks/overview/). The platform improves the performance and resilience of these applications, even at very high scale. It also protects them and the connected infrastructure, and it observes them in real time.

To use Azion, [create an account](https://console.azion.com/signup). It is free and does not need a credit card. Then put your first application live: the [first deploy](/en/documentation/get-started/first-deploy/) starts from a template, a GitHub repository, or the CLI, and takes a few minutes. If your company already uses Azion, ask an administrator for an invite instead.
