This guide instructs you through running your first function on Azion. When you finish, you will have:

- Written a Hello World function in the ES Modules pattern.
- Turned on the Functions module in an application.
- Instantiated the function in that application.
- Created a rule that runs the function for one path.
- Verified the response with `curl`.

Nothing invokes a function on its own. You write the function in [Functions](/en/documentation/build/functions/). It runs inside an application that has the **Functions** module turned on. A function instance links the function to that application. A rule in [Rules Engine](/en/documentation/build/applications/reference/rules-engine/) with the **Run Function** behavior calls the instance when a request matches its criteria. This guide creates each object in that order.

---

## Prerequisites

- An Azion account with access to [Azion Console](/en/documentation/account/guides/how-to-access-azion-console/).
- An application. To create one, refer to [Applications quickstart](/en/documentation/build/applications/quickstart/).
- Familiarity with JavaScript.

---

## 1. Write the function

The function uses the ES Modules pattern: an `export default` object whose `fetch` handler returns an HTML page. For the handler signature, refer to [Handlers](/en/documentation/build/functions/reference/handlers/).

1. Access [Azion Console](https://console.azion.com/) > **Functions**.
2. Select **+ Function**.
3. Enter a name for the function.
4. In the code editor, enter the following code:

<Code lang="javascript" code={`const html = \`<!DOCTYPE html>
<body>
  <h1>Hello World</h1>
  <p>This markup was generated by Azion - Functions.</p>
</body>\`;

export default {
  fetch: async (request, env, ctx) => {
    return new Response(html, {
      headers: {
        "content-type": "text/html;charset=UTF-8",
      },
    });
  },
};`} />

5. Select **Save**.

The function is saved. Nothing runs it until you instantiate it in an application.

## 2. Turn on the Functions module

An application runs function instances only with the **Functions** module on.

1. Access [Azion Console](https://console.azion.com/) > **Applications**.
2. Select your application.
3. Turn on the **Functions** module.
4. Select **Save**.

The application can run function instances.

:::note
With the Functions module on, compute time and invocations can generate usage costs. For more information, refer to [Pricing](/en/documentation/platform/pricing/#functions).
:::

## 3. Instantiate the function in the application

A function instance links one saved function to one application.

1. Access [Azion Console](https://console.azion.com/) > **Applications**.
2. Select your application.
3. Go to the **Functions Instances** tab.
4. Select **+ Function Instance**.
5. Enter `Hello World function` as the name.
6. Select the function you saved.
7. Select **Save**.

The new instance appears in the **Functions Instances** tab. Nothing runs it until a rule calls it.

## 4. Create a rule that runs the function

A rule in the application's **Rules Engine** tab calls the function instance when a request matches its criteria. This rule matches requests to the path `/hello-world`.

1. Access [Azion Console](https://console.azion.com/) > **Applications**.
2. Select your application.
3. Go to the **Rules Engine** tab.
4. Select **+ Rule**.
5. Enter `Run Hello World` as the name.
6. Select _Request Phase_.
7. In the **Criteria** section, select the variable `${uri}`.
8. As the operator, select _is equal_.
9. Enter `/hello-world` as the argument.
10. In the **Behaviors** section, select _Run Function_.
11. Select the _Hello World function_ instance.
12. Select **Save**.

The rule appears in the **Rules Engine** tab. Requests to `/hello-world` on your application run the function instance.

## 5. Verify the response

Your application answers requests to `/hello-world` with the response the function returns. New rules can take a few minutes to propagate. On an unexpected response, wait and retry before diagnosing.

Request the path, replacing `xxxxxxxxx.map.azionedge.net` with your application's domain:

<Code lang="bash" code={`curl https://xxxxxxxxx.map.azionedge.net/hello-world`} />

The response body is the HTML page the function returns:

```html
<!DOCTYPE html>
<body>
  <h1>Hello World</h1>
  <p>This markup was generated by Azion - Functions.</p>
</body>
```

Your first function runs on Azion's distributed network.
