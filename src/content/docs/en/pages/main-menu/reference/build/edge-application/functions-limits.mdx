This reference lists the default limits for a function that runs on [Azion Runtime](/en/documentation/runtime/overview/). They bound execution time, memory and code size, the request and response a function processes, and the configuration it receives. A function invoked from [Firewall](/en/documentation/secure/firewall/) has the same default values for JSON args, memory, code size, environment variables, sub-requests, and CPU time.

:::tip[Increase limits]
To request a higher limit for your plan, contact [technical support](/en/documentation/services/support/).
:::

---

## Execution time limits

Execution time limits bound how long one invocation of a function runs. CPU time counts active computation only, while wall-clock time counts total elapsed time, including I/O wait, `fetch()` calls, and async operations.

| Limit | Value | Description |
| --- | --- | --- |
| CPU time | 2 s | Maximum CPU time a function consumes per invocation. Counts active computation only, not wall-clock time. A function that exceeds it is terminated. |
| Wall-clock time | 5 min | Maximum total elapsed time for one invocation, including I/O wait, `fetch()` calls, and async operations. |
| Cold start | 2 s | Maximum time for a function to initialize before it handles its first request. |

---

## Memory and code size limits

Memory limits bound a single execution context of a function. Code size limits bound the source code you upload, and the ceiling depends on the interface you deploy through.

| Limit | Value | Description |
| --- | --- | --- |
| Memory per isolate | 512 MB | Maximum memory available to a single function execution context (isolate), including heap, stack, and all runtime allocations. |
| Code size (Azion Console) | 6 MB | Maximum size of the function source code when created or edited through Azion Console. |
| Code size (API) | 20 MB | Maximum size of the function source code when deployed through the Azion API. |

---

## Request and response limits

Request and response limits bound the URL, headers, and body a function processes, and the outbound `fetch()` calls it makes in one invocation.

| Limit | Value | Description |
| --- | --- | --- |
| URL size | 16 KB | Maximum size of the request URL a function processes, including the path and query string. |
| Header size | 64 KB | Maximum total size of all HTTP request headers combined that a function reads or writes. |
| Outbound sub-requests | 50 per invocation | Maximum number of outbound `fetch()` calls a function makes during a single invocation. |

The body size limit varies by service plan. It bounds the HTTP request or response body that a function processes.

| Scope | Plan | Limit | Raisable |
| --- | --- | --- | --- |
| Request or response body | Developer | 100 MB | Yes, on request |
| Request or response body | Business | 200 MB | Yes, on request |
| Request or response body | Enterprise | 500 MB | Yes, on request |
| Request or response body | Mission Critical | 500 MB | Yes, on request |

---

## Configuration limits

Configuration limits bound the JSON args passed to a [function instance](/en/documentation/build/functions/reference/functions-instances/) and the [environment variables](/en/documentation/products/functions/environment-variables/) a function reads.

| Limit | Value | Description |
| --- | --- | --- |
| JSON args | 100 KB | Maximum size of the JSON args object passed to a function instance. A larger object causes the function to fail at instantiation. |
| Environment variables | 32 KB | Maximum total size of all environment variables combined for a single function. |
