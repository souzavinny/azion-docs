You can read the cache indicators Azion returns for a request. Add a debug header in Google Chrome, then inspect the response headers in Developer Tools.

## Prerequisites

- Google Chrome
- The [ModHeader](https://modheader.com/) extension for Google Chrome
- An application delivering content through Azion

---

## Add the debug header

ModHeader attaches the header to every request the browser sends, so the edge returns its cache data for the page you are already viewing.

To add the header:

1. Install the [ModHeader](https://chrome.google.com/webstore/detail/modheader-modify-http-hea/idgpnmonknjnojddfkpgkljpfnnfcklj) extension and select **Add to Chrome**.
2. In the Google Chrome toolbar, select **Extensions** and then select **ModHeader**.
3. In the **Profile** page, select **Request headers**.
4. In **Name**, enter `Pragma`.
5. In **Value**, enter `azion-debug-cache`.
6. Select the **Pause ModHeader** icon.
7. Select the **Resume ModHeader** icon.

ModHeader now sends the debug header with every request.

---

## Read the cache indicators

Developer Tools reports the response headers for each request the page makes, including the cache headers the edge adds.

To read the indicators:

1. In the Google Chrome toolbar, select the **Customize and Control Google Chrome** button, represented by the ︙ icon.
2. Go to **More Tools** > **Developer Tools**.
3. Select the **Network** tab.
4. Access the page whose content is cached.
5. In the request list, select the cached content.
6. Select the **Headers** tab.

The response headers list the cache indicators for that object:

| Field | Description |
| --- | --- |
| X-Cache | Status of the request, which is either HIT, MISS, EXPIRED, UPDATING or STALE. |
| X-Cache-Key | Cache key of the object. Normally consists of the combination of host + URI + arguments. |
| X-Cache-File | Cache file of the object, consisting of the md5 of the cache key. |
| X-Cache-Since | Unix Time Stamp* of when the object enters the cache. |
| X-Cache-Expire | Unix Time Stamp* of when the object leaves the cache. |
| X-Cache-Expire-In | Time that the object will remain in cache, in seconds. |
| X-Cache-Valid | Time set for the object to be in the cache. This time can be set unconditionally on the webserver or can come from the origin via Cache-Control headers. |
| X-Cache-Config | ID of the configuration of the virtual host on the webserver. This value is generated by the Azion Console. |
| X-Cache-ID | Unique request ID. |

*\* You can convert Unix Time Stamp into the standard format using the [Unix Time Stamp website](http://www.unixtimestamp.com/).*
