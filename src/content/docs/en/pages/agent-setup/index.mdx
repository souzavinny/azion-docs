## What your agent can use

- [Azion MCP server](/en/documentation/devtools/mcp/): live search over docs, code samples, CLI, API, and Terraform, plus deploy tools — authenticated with a [personal token](/en/documentation/account/reference/personal-tokens/).
- [llms.txt](https://www.azion.com/llms.txt): machine-readable index of the documentation.
- [For AI Agents](/en/documentation/devtools/for-ai-agents/): canonical facts — current product names, API base URL, auth format.
- [Azion CLI](/en/documentation/products/azion-cli/overview/): real build and deploy commands for terminal agents.

## Prompts to try

- "Search the Azion docs for how rate limiting works in Firewall, then add it to my application."
- "Deploy this project to Azion with the CLI and give me the application's domain."
- "Create a Rules Engine rule that redirects `/old-blog/*` to `/blog/*`."
