[GitHub Copilot](https://github.com/features/copilot) runs as an agent inside VS Code. Connect it to Azion's live docs and MCP tools in four steps.

## Quick start

<Steps>

<div class="step">

**Install the pieces** — VS Code with the GitHub Copilot extension and an active Copilot subscription.

</div>

<div class="step">

**Connect the Azion MCP server** — create `.vscode/mcp.json` in your project root, replacing `YOUR_PERSONAL_TOKEN` with an [Azion personal token](/en/documentation/account/reference/personal-tokens/):

<Code lang="json" code={`{
    "servers": {
        "azion": {
            "type": "http",
            "url": "https://mcp.azion.com",
            "headers": {
                "Authorization": "Bearer YOUR_PERSONAL_TOKEN"
            }
        }
    }
}`} />

</div>

<div class="step">

**Add Azion context** — copy the ready-made block from [For AI Agents](/en/documentation/devtools/for-ai-agents/) into `.github/copilot-instructions.md` in your repository.

</div>

<div class="step">

**Verify** — open Copilot Chat in agent mode, start the server when prompted, and ask:

<Code lang="text" code={`Using the Azion MCP server, search the docs for how to create a Workload.`} />

The Azion tools should appear in the tools picker, and the agent should answer through `search_azion_docs_and_site`.

</div>

</Steps>
