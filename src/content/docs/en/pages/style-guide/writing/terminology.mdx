## Use current product names

Azion renamed its products and platform resources. The current names below are the only correct forms in new text, in both languages.

| Use | Not |
| --- | --- |
| Applications | Edge Application, Edge Applications |
| Functions | Edge Functions |
| Firewall | Edge Firewall |
| Connectors | Edge Connector |
| Console | Real-Time Manager |
| Cache | Edge Cache |
| Application Accelerator | Application Acceleration |
| AI Inference | Edge AI |
| Image Processor | Image Processing |
| Orchestrator | Edge Orchestrator |
| KV Store | Edge KV |
| Object Storage | Edge Storage |
| SQL Database | Edge SQL |
| Network Shield | Network Layer Protection |
| Data Stream | Data Streaming |
| Azion Platform | Azion Edge Platform |
| Azion Marketplace | Marketplace da Azion |

**Azion Platform** is the canonical platform name, and **Azion Web Platform** is an accepted alternative. Prefer **Azion Platform** in security content. Never write **Azion Edge Platform**, in any language.

The old names are legacy because the rename retired them. They still appear in old pages, URLs, and directory names, so they can look current. Treat these names as history, not as synonyms.

## Name a module as a product

**Applications**, **Firewall**, **Connectors**, and **Console** are platform resources: capabilities of the platform itself. The modules of a resource are products. Name the product first, with the resource as context.

- Correct: `Web Application Firewall (WAF) is a Firewall module that inspects HTTP and HTTPS requests.`
- Incorrect: `Firewall is a product that includes WAF.`

## Lowercase the thing the customer builds

A product name is capitalized. The thing a customer creates with it is a common noun, and it stays lowercase.

- Correct: `Use **Applications** to build your own applications.`
- Correct: `**Functions** runs your functions at Azion's distributed network.`
- Incorrect: `Deploy your first Application.`

The distinction keeps the product name meaningful. A page that capitalizes both leaves the reader unable to tell the product from the object.

## Keep historical names in historical documents

Changelogs, release notes, and dated agreements record what was true on the day of publication. These documents keep the product names they shipped with. A Terms of Service from 2020 keeps the names that were correct in 2020.

Do not rename products in a historical document. An updated name rewrites the record and detaches the text from its date.

## Leave these terms in English

These terms are generic technical vocabulary, not product names. They stay in English in both languages:

`data center` · `serverless` · `on-premise` · `template` · `compliance` · `e-commerce` · `e-mail` · `keywords` · `meta description`

A translation creates a second name for a concept the reader already knows in English. The documentation uses one term for one concept, on every page.

The strings `edge`, `edge computing`, and `edge location` also stay untranslated where they already appear. That is guidance for translation, not permission to use them. New text names Azion's distributed network instead.

## Apply the Portuguese substitutions

On Portuguese pages, use the terms in the right column:

| Avoid | Use |
| --- | --- |
| borda | rede distribuída |
| aplicativo | aplicação |
| desempenho | performance |
| cacheado | armazenado em cache |
| computação na borda | rede distribuída da Azion |
| Plataforma na Borda da Azion | Plataforma da Azion |
| Plataforma Edge da Azion | Plataforma da Azion |
| nodo | node |
| centro de dados | data center |

Do not replace `módulo`. It is the correct word for a module of a product or a resource: `WAF é um módulo do Firewall`. Avoid `módulo` only when it stands loosely for a whole product.

These substitutions cover the choices that go wrong most often in translation. The full set of translation rules is in [Bilingual pages](/en/documentation/style-guide/conventions/bilingual/).

## Avoid the forbidden expressions

Never use these expressions, in any language:

`digital landscape` / `paisagem digital` · `digital transformation` / `transformação digital` · `empower` / `capacitar` · `plethora` / `plétora` · `shed light` / `esclarecer` · `realm` / `reino` · `beacon` / `farol`

These expressions promote; they do not describe. Documentation states behavior and limits, and the reader already chose the product. The full vocabulary rules are in [Word choice](/en/documentation/style-guide/writing/word-choice/).

## Write titles in sentence case

Capitalize the first word and proper nouns only. The rule applies to titles and headings in both languages.

- Correct: `Configure cache policies`
- Incorrect: `Configure Cache Policies`

A product name keeps its capitals in any position, because it is a proper noun.

## Ask when a name is not listed

When this guide does not list a product name, ask before you write it. Do not infer a name from a URL, a directory name, or an older page.

Repository directories still carry legacy names, such as `edge-application/` and `edge-firewall/`, that the prose no longer uses. A path shows where a file lives, not the current name of the product.
