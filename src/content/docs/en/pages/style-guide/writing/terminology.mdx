## Use current product names

Azion renamed several products. The current names below are the only correct forms in new text, in both languages.

| Use | Not |
| --- | --- |
| Applications | Edge Application, Edge Applications |
| Functions | Edge Functions |
| Firewall | Edge Firewall |
| Azion Web Platform | Azion Edge Platform |
| Azion Marketplace | Marketplace da Azion |

**Azion Platform** is an accepted short form of **Azion Web Platform**.

The old names are legacy because the rename retired them. They still appear in old pages, URLs, and directory names, so they can look current. Treat these names as history, not as synonyms.

## Keep historical names in historical documents

Changelogs, release notes, and dated agreements record what was true on the day of publication. These documents keep the product names they shipped with. A Terms of Service from 2020 keeps the names that were correct in 2020.

Do not rename products in a historical document. An updated name rewrites the record and detaches the text from its date.

## Leave these terms in English

These terms are generic technical vocabulary, not product names. They stay in English in both languages:

`edge computing` · `edge` · `edge location` · `data center` · `serverless` · `on-premise` · `template` · `compliance` · `e-commerce` · `e-mail` · `keywords` · `meta description`

A translation creates a second name for a concept the reader already knows in English. The documentation uses one term for one concept, on every page.

These substitutions cover the choices that go wrong most often in translation. The full set of translation rules is in [Bilingual pages](/en/documentation/style-guide/conventions/bilingual/).

## Avoid the forbidden expressions

Never use these expressions, in any language:

`digital landscape` / `paisagem digital` · `digital transformation` / `transformação digital` · `empower` / `capacitar` · `plethora` / `plétora` · `shed light` / `esclarecer` · `realm` / `reino` · `beacon` / `farol`

These expressions promote; they do not describe. Documentation states behavior and limits, and the reader already chose the product. The full vocabulary rules are in [Word choice](/en/documentation/style-guide/writing/word-choice/).

## Write titles in sentence case

Capitalize the first word and proper nouns only. The rule applies to titles and headings in both languages.

- Correct: `How to configure cache policies`
- Incorrect: `How To Configure Cache Policies`

A product name keeps its capitals in any position, because it is a proper noun.

## Ask when a name is not listed

When this guide does not list a product name, ask before you write it. Do not infer a name from a URL, a directory name, or an older page.

Repository directories still carry legacy names, such as `edge-application/` and `edge-firewall/`, that the prose no longer uses. A path shows where a file lives, not the current name of the product.
