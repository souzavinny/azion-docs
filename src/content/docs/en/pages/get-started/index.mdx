Before you can use Azion products, first create an account. Starting is free and doesn't ask for a credit card.

<LinkButton link="https://console.azion.com/signup" label="Create your account" target="_blank" />

If your company already uses Azion, ask an administrator to invite you rather than opening a second account. Permissions are granted per team, so what you can see and change depends on the team you belong to. Larger organizations usually set this up with [teams and permissions](/en/documentation/account/guides/teams-permissions/) and [single sign-on](/en/documentation/account/guides/sso/).

## Learn about Azion's offerings

### Build

An [Application](/en/documentation/build/applications/) is the unit you deploy. It runs on every point of the network at once, so the code answering a request is already near the person making it, and there is no region to pick and no server to size. [Functions](/en/documentation/build/applications/functions/) run your JavaScript or WebAssembly inside that same request, and [AI Inference](/en/documentation/build/ai-inference/) puts hosted models behind an OpenAI-compatible endpoint without any GPU to manage.

Code that needs state reaches for [SQL Database](/en/documentation/store/sql-database/), [KV Store](/en/documentation/store/kv-store/), or [Object Storage](/en/documentation/store/object-storage/). These sit where the code runs, which is the point: a read doesn't travel back to a database parked in one region.

Reading about this only gets you so far. The [first deploy](/en/documentation/get-started/first-deploy/) puts something live in a few minutes from a template, a GitHub repository, or the CLI, and most frameworks have [a build path already written](/en/documentation/get-started/frameworks/overview/).

### Protect and deliver

Everything you deploy can sit behind a [Firewall](/en/documentation/secure/firewall/quickstart/), which is also what turns on DDoS mitigation and gives the other modules somewhere to attach. From there, [WAF](/en/documentation/secure/waf/) inspects requests for injection and scripting attacks, [Bot Manager](/en/documentation/secure/bot-manager/) scores automated traffic, and [Network Shield](/en/documentation/secure/network-shield/) drops whole IP ranges, ASNs, or countries before they cost you anything.

The pieces that get traffic to your application live nearby: [Certificate Manager](/en/documentation/secure/certificate-manager/) for the TLS your own domain needs, and [Edge DNS](/en/documentation/secure/edge-dns/) if you want the authoritative zone here too.

### Observe and automate

[Real-Time Metrics](/en/documentation/observe/real-time-metrics/) and [Real-Time Events](/en/documentation/observe/real-time-events/) answer what is happening now, which is usually the question you have during an incident. For everything after that, [Data Stream](/en/documentation/observe/data-stream/) ships logs to the tools your team already watches.

Once the shape of your setup stops changing, stop clicking it: the [CLI](/en/documentation/products/azion-cli/overview/), the [API](/en/documentation/devtools/api/), the [Terraform provider](/en/documentation/products/terraform-provider/), and [Orchestrator](/en/documentation/deploy/orchestrator/) all describe the same platform as code.

Looking for a specific task rather than the tour? The [guides](/en/documentation/guides/) are indexed by what you're trying to do. If something doesn't work the way this page describes, the [Discord community](https://discord.com/invite/Yp9N7RMVZy) and [Azion support](/en/documentation/services/support/) are both worth a message.
