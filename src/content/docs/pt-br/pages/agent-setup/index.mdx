## O que seu agente pode usar

- [Servidor MCP da Azion](/pt-br/documentacao/devtools/mcp/): busca ao vivo em documentação, exemplos de código, CLI, API e Terraform, além de ferramentas de deploy — autenticado com um [personal token](/pt-br/documentacao/account/reference/personal-tokens/).
- [llms.txt](https://www.azion.com/llms.txt): índice da documentação legível por máquinas.
- [Para agentes de IA](/pt-br/documentacao/devtools/for-ai-agents/): fatos canônicos — nomes atuais dos produtos, URL base da API, formato de autenticação.
- [Azion CLI](/pt-br/documentacao/produtos/azion-cli/visao-geral/): comandos reais de build e deploy para agentes de terminal.
