O [Cache](/pt-br/documentacao/build/cache/) aplica limites default aos valores de TTL que você define, aos objetos que armazena e às operações de purge que você executa. Apenas o limite de operações de purge muda conforme o plano de suporte da conta. Todos os outros limites desta página são iguais em todos os planos.

:::tip[dica]
**Aumente seus limites** <br></br>
Contate o [suporte técnico](/pt-br/documentacao/services/support/) para solicitar um limite maior para o seu plano.
:::

---

## TTL de cache

O TTL de cache define por quanto tempo um objeto permanece em cache nos edge nodes da Azion. O valor mínimo que você pode definir depende dos módulos ativos na aplicação, então [Application Accelerator](/pt-br/documentacao/build/application-accelerator/) e [Tiered Cache](/pt-br/documentacao/build/cache/tiered-cache/) movem esse piso.

| Escopo | Limite |
| --- | --- |
| TTL de cache default | 60 segundos |
| TTL de cache mínimo | 60 segundos |
| TTL de cache mínimo com Application Accelerator ativo | 0 segundos |
| TTL de cache mínimo com Tiered Cache ativo | 3 segundos |
| TTL de cache máximo | 31.536.000 segundos |
| Janela de stale default | 300 segundos |

A Azion aplica a janela default de [stale cache](/pt-br/documentacao/build/cache/como-funciona/#stale-cache) quando a cache setting sobrescreve os headers da origem, ou quando a origem não envia a diretiva `stale-while-revalidate`. Quando a origem envia a diretiva e a cache setting honra os headers da origem, o valor da origem decide por quanto tempo o objeto é servido stale.

## Tamanhos de objeto e de fragmento

O Cache armazena cada objeto nos edge nodes da Azion até um tamanho máximo. O [Large File Optimization](/pt-br/documentacao/build/cache/reference/cache-settings/#large-file-optimization) divide um arquivo maior em fragmentos e armazena cada fragmento sob a sua própria cache key.

| Escopo | Limite |
| --- | --- |
| Tamanho de objeto único em cache | 10 GB |
| Tamanho de slice de arquivo | 1.024 kB |

O tamanho de slice de arquivo é o tamanho de fragmento que o Large File Optimization usa. Para alterar o intervalo de fragmentação, [contate a equipe de Vendas](https://www.azion.com/pt-br/contato/).

## Tiered Cache

Tiered Cache é um módulo do Cache que adiciona uma segunda camada de cache entre os edge nodes da Azion e seus servidores de origem. Essa camada carrega os seus próprios limites de TTL, e eles são mais estreitos que os limites do cache nos edge nodes da Azion.

| Escopo | Limite |
| --- | --- |
| TTL mínimo no Tiered Cache | 3 segundos |
| TTL máximo no Tiered Cache | 2.592.000 segundos |

:::note[nota]
Tiered Cache não suporta bypass cache. Uma [regra de Bypass Cache](/pt-br/documentacao/build/applications/reference/rules-engine/#bypass-cache) se aplica ao cache nos edge nodes da Azion. Uma aplicação com uma cache setting de Tiered Cache ativa continua armazenando em cache na camada tiered pelo TTL mínimo.
:::

## Real-Time Purge

O [Real-Time Purge](/pt-br/documentacao/build/cache/reference/real-time-purge/) deleta objetos em cache antes que o TTL deles expire. Os limites abaixo delimitam o tamanho de um argumento de purge, a taxa de operações de purge e o histórico de purge.

| Escopo | Limite |
| --- | --- |
| Número de requisições no histórico | 1.000.000 requisições |
| Tempo do histórico de purge | 6 meses |
| Tamanho de URL e de cache key | 4.096 caracteres |
| Operações de URL e de cache key por cliente | 200 requisições com 50 objetos por requisição |
| Operações de URL e de cache key por minuto | 10.000 objetos a cada 60 segundos |
| Operações de wildcard por dia (intervalo de 24 horas) | 2.000 requisições |
| Tamanho de wildcard | 256 caracteres |
| Wildcards por requisição | 1 |

## Limites por plano de suporte

Um limite do Cache muda conforme o plano de suporte da conta: o número de operações de purge por mês.

| Escopo | Developer | Business, Enterprise e Mission-Critical |
| --- | --- | --- |
| Operações de purge | 1.000 por mês | 1.000 por mês<br />Operações de purge adicionais são negociáveis |

Para o preço das operações de purge, consulte [Preços](/pt-br/documentacao/platform/pricing/#cache).
