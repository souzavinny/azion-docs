Este guia orienta você a executar sua primeira função na Azion. Ao terminar, você terá:

- Escrito uma função Hello World no padrão ES Modules.
- Ativado o módulo Functions em uma aplicação.
- Instanciado a função nessa aplicação.
- Criado uma regra que executa a função para um caminho.
- Verificado a resposta com `curl`.

Nada invoca uma função por si só. Você escreve a função em [Functions](/pt-br/documentacao/build/functions/). Ela é executada dentro de uma aplicação com o módulo **Functions** ativado. Uma instância de função vincula a função a essa aplicação. Uma regra em [Rules Engine](/pt-br/documentacao/build/applications/reference/rules-engine/) com o behavior **Run Function** chama a instância quando uma requisição corresponde aos seus critérios. Este guia cria cada objeto nessa ordem.

---

## Pré-requisitos

- Uma conta Azion com acesso ao [Azion Console](/pt-br/documentacao/account/guides/como-acessar-o-azion-console/).
- Uma aplicação. Para criar uma, consulte [Quickstart de Applications](/pt-br/documentacao/build/applications/quickstart/).
- Familiaridade com JavaScript.

---

## 1. Escreva a função

A função usa o padrão ES Modules: um objeto `export default` cujo handler `fetch` retorna uma página HTML. Para a assinatura do handler, consulte [Handlers](/pt-br/documentacao/build/functions/reference/handlers/).

1. Acesse [Azion Console](https://console.azion.com/) > **Functions**.
2. Selecione **+ Function**.
3. Insira um nome para a função.
4. No editor de código, insira o seguinte código:

<Code lang="javascript" code={`const html = \`<!DOCTYPE html>
<body>
  <h1>Hello World</h1>
  <p>This markup was generated by Azion - Functions.</p>
</body>\`;

export default {
  fetch: async (request, env, ctx) => {
    return new Response(html, {
      headers: {
        "content-type": "text/html;charset=UTF-8",
      },
    });
  },
};`} />

5. Selecione **Save**.

A função está salva. Nada a executa até que você a instancie em uma aplicação.

## 2. Ative o módulo Functions

Uma aplicação executa instâncias de função somente com o módulo **Functions** ativado.

1. Acesse [Azion Console](https://console.azion.com/) > **Applications**.
2. Selecione sua aplicação.
3. Ative o módulo **Functions**.
4. Selecione **Save**.

A aplicação pode executar instâncias de função.

:::note[Nota]
Com o módulo Functions ativado, tempo de computação e invocações podem gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/platform/pricing/#functions).
:::

## 3. Instancie a função na aplicação

Uma instância de função vincula uma função salva a uma aplicação.

1. Acesse [Azion Console](https://console.azion.com/) > **Applications**.
2. Selecione sua aplicação.
3. Vá para a aba **Functions Instances**.
4. Selecione **+ Function Instance**.
5. Insira `Hello World function` como o nome.
6. Selecione a função que você salvou.
7. Selecione **Save**.

A nova instância aparece na aba **Functions Instances**. Nada a executa até que uma regra a chame.

## 4. Crie uma regra que execute a função

Uma regra na aba **Rules Engine** da aplicação chama a instância de função quando uma requisição corresponde aos seus critérios. Esta regra corresponde a requisições para o caminho `/hello-world`.

1. Acesse [Azion Console](https://console.azion.com/) > **Applications**.
2. Selecione sua aplicação.
3. Vá para a aba **Rules Engine**.
4. Selecione **+ Rule**.
5. Insira `Run Hello World` como o nome.
6. Selecione _Request Phase_.
7. Na seção **Criteria**, selecione a variável `${uri}`.
8. Como operador, selecione _is equal_.
9. Insira `/hello-world` como o argumento.
10. Na seção **Behaviors**, selecione _Run Function_.
11. Selecione a instância _Hello World function_.
12. Selecione **Save**.

A regra aparece na aba **Rules Engine**. Requisições para `/hello-world` na sua aplicação executam a instância de função.

## 5. Verifique a resposta

Sua aplicação responde a requisições para `/hello-world` com a resposta que a função retorna. Novas regras podem levar alguns minutos para propagar. Em caso de resposta inesperada, aguarde e tente novamente antes de diagnosticar.

Faça uma requisição para o caminho e substitua `xxxxxxxxx.map.azionedge.net` pelo domínio da sua aplicação:

<Code lang="bash" code={`curl https://xxxxxxxxx.map.azionedge.net/hello-world`} />

O corpo da resposta é a página HTML que a função retorna:

```html
<!DOCTYPE html>
<body>
  <h1>Hello World</h1>
  <p>This markup was generated by Azion - Functions.</p>
</body>
```

Sua primeira função é executada na rede distribuída da Azion.
