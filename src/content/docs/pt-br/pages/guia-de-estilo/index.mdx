Este guia descreve como a Azion escreve sua documentação. Use este guia quando você escrever uma página nova, traduzir uma página ou revisar o trabalho de outra pessoa. As regras existem para que todas as páginas tenham a mesma leitura, sejam bem traduzidas e continuem úteis quando uma máquina recupera uma seção sozinha.

## O que este guia cobre

- [Voz](/pt-br/documentacao/guia-de-estilo/escrita/voz/): o registro que todas as páginas usam.
- [Estrutura de frases](/pt-br/documentacao/guia-de-estilo/escrita/estrutura-de-frases/): as regras de frase, adaptadas do ASD-STE100.
- [Procedimentos](/pt-br/documentacao/guia-de-estilo/escrita/procedimentos/): a gramática de passo que todo procedimento numerado segue.
- [Escolha de palavras](/pt-br/documentacao/guia-de-estilo/escrita/escolha-de-palavras/): vocabulário a evitar e os padrões que parecem gerados por máquina.
- [Terminologia](/pt-br/documentacao/guia-de-estilo/escrita/terminologia/): nomes de produtos e regras de tradução.
- [Títulos](/pt-br/documentacao/guia-de-estilo/formatacao/titulos/), [formatação de texto](/pt-br/documentacao/guia-de-estilo/formatacao/texto/) e [código](/pt-br/documentacao/guia-de-estilo/formatacao/codigo/): como o conteúdo é formatado.
- [Estratégia de conteúdo](/pt-br/documentacao/guia-de-estilo/conteudo/escolher-um-tipo-de-conteudo/): a [arquitetura de informação](/pt-br/documentacao/guia-de-estilo/conteudo/arquitetura-de-informacao/), os tipos de página e como escolher um.
- [Convenções de arquivos](/pt-br/documentacao/guia-de-estilo/convencoes/frontmatter/): frontmatter e [páginas bilíngues](/pt-br/documentacao/guia-de-estilo/convencoes/paginas-bilingues/).
- [Componentes](/pt-br/documentacao/guia-de-estilo/componentes/), [Documentação de API](/pt-br/documentacao/guia-de-estilo/api-docs/) e [Como escrevemos a documentação](/pt-br/documentacao/guia-de-estilo/como-documentamos/): seções reservadas para conteúdo que ainda não foi escrito.

## Escopo

Este guia cobre escrita e arquitetura de informação. Componentes, design visual e layout de página estão fora das regras de escrita: a seção [Componentes](/pt-br/documentacao/guia-de-estilo/componentes/) guarda o lugar até esse conteúdo chegar.

## Onde as regras vivem

A fonte canônica das regras de escrita é o diretório `.agents` de [aziontech/docs](https://github.com/aziontech/docs): um sistema autossuficiente que gera e revisa páginas sem consultar o repositório. Este guia é a versão legível para humanos dessas regras. Uma regra muda primeiro em `.agents`, e estas páginas são regeneradas a partir dele. O diretório `.agents` também carrega o que este guia não cobre: os componentes MDX, os arquivos de menu, os validadores de build e os testes de conformidade.

## O guia segue as próprias regras

Todas as páginas desta seção passam pelas regras que descrevem: os limites de frase, as regras de títulos e as metas de tamanho. Quando uma regra não funciona aqui, a regra muda antes de qualquer pessoa precisar segui-la.
