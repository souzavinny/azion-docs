## Use os nomes atuais dos produtos

A Azion renomeou seus produtos e recursos de plataforma. Os nomes atuais abaixo são as únicas formas corretas em texto novo, nos dois idiomas.

| Use | Não use |
| --- | --- |
| Applications | Edge Application, Edge Applications |
| Functions | Edge Functions |
| Firewall | Edge Firewall |
| Connectors | Edge Connector |
| Console | Real-Time Manager |
| Cache | Edge Cache |
| Application Accelerator | Application Acceleration |
| AI Inference | Edge AI |
| Image Processor | Image Processing |
| Orchestrator | Edge Orchestrator |
| KV Store | Edge KV |
| Object Storage | Edge Storage |
| SQL Database | Edge SQL |
| Network Shield | Network Layer Protection |
| Data Stream | Data Streaming |
| Azion Platform | Azion Edge Platform |
| Azion Marketplace | Marketplace da Azion |

**Azion Platform** é o nome canônico da plataforma, e **Azion Web Platform** é uma alternativa aceita. Prefira **Azion Platform** em conteúdo de segurança. Nunca escreva **Azion Edge Platform**, em nenhum idioma.

Os nomes antigos são legados porque a renomeação os aposentou. Eles ainda aparecem em páginas antigas, URLs e nomes de diretórios, e por isso parecem atuais. Trate esses nomes como história, não como sinônimos.

## Nomeie um módulo como produto

**Applications**, **Firewall**, **Connectors** e **Console** são recursos de plataforma: capacidades da própria plataforma. Os módulos de um recurso são produtos. Nomeie o produto primeiro, com o recurso como contexto.

- Correto: `Web Application Firewall (WAF) é um módulo do Firewall que inspeciona requisições HTTP e HTTPS.`
- Incorreto: `Firewall é um produto que inclui o WAF.`

## Mantenha nomes históricos em documentos históricos

Changelogs, release notes e contratos datados registram o que era verdade no dia da publicação. Esses documentos mantêm os nomes de produto da época da publicação. Um Termos de Serviço de 2020 mantém os nomes que eram corretos em 2020.

Não renomeie produtos em um documento histórico. Um nome atualizado reescreve o registro e separa o texto da sua data.

## Deixe estes termos em inglês

Estes termos são vocabulário técnico genérico, não nomes de produto. Eles ficam em inglês nos dois idiomas:

`edge computing` · `edge` · `edge location` · `data center` · `serverless` · `on-premise` · `template` · `compliance` · `e-commerce` · `e-mail` · `keywords` · `meta description`

Uma tradução cria um segundo nome para um conceito que o leitor já conhece em inglês. A documentação usa um termo para cada conceito, em todas as páginas.

## Aplique as substituições do português

Nas páginas em português, use os termos da coluna da direita:

| Evite | Use |
| --- | --- |
| borda | edge |
| aplicativo | aplicação |
| desempenho | performance |
| cacheado | armazenado em cache |
| computação na borda | edge computing |
| Plataforma na Borda da Azion | Plataforma da Azion |
| Plataforma Edge da Azion | Plataforma da Azion |
| nodo | node |
| centro de dados | data center |

Não substitua `módulo`. É a palavra correta para um módulo de um produto ou de um recurso: `WAF é um módulo do Firewall`. Evite `módulo` apenas quando a palavra nomeia vagamente um produto inteiro.

Essas substituições cobrem as escolhas que mais dão errado em tradução. As regras completas de tradução estão em [Páginas bilíngues](/pt-br/documentacao/guia-de-estilo/convencoes/paginas-bilingues/).

## Evite as expressões proibidas

Nunca use estas expressões, em nenhum idioma:

`digital landscape` / `paisagem digital` · `digital transformation` / `transformação digital` · `empower` / `capacitar` · `plethora` / `plétora` · `shed light` / `esclarecer` · `realm` / `reino` · `beacon` / `farol`

Essas expressões promovem; elas não descrevem. A documentação declara comportamento e limites, e o leitor já escolheu o produto. As regras completas de vocabulário estão em [Escolha de palavras](/pt-br/documentacao/guia-de-estilo/escrita/escolha-de-palavras/).

## Use maiúscula só na primeira palavra do título

Em um título, apenas a primeira palavra e os nomes próprios começam com maiúscula. A regra vale para títulos e headings nos dois idiomas.

- Correto: `Configurar políticas de cache`
- Incorreto: `Configurar Políticas De Cache`

Um nome de produto mantém as maiúsculas em qualquer posição, porque é um nome próprio.

## Pergunte quando um nome não estiver listado

Quando um nome de produto não está neste guia, pergunte antes de escrever. Não deduza um nome a partir de uma URL, de um nome de diretório ou de uma página antiga.

Os diretórios do repositório ainda carregam nomes legados, como `edge-application/` e `edge-firewall/`, que o texto não usa mais. Um caminho mostra a localização de um arquivo, não o nome atual do produto.
