Você pode ler os indicadores de cache que a Azion retorna em uma requisição. Adicione um cabeçalho de debug no Google Chrome e inspecione os cabeçalhos de resposta nas Developer Tools.

## Pré-requisitos

- Google Chrome
- A extensão [ModHeader](https://modheader.com/) para Google Chrome
- Uma application entregando conteúdo pela Azion

---

## Adicione o cabeçalho de debug

O ModHeader anexa o cabeçalho a todas as requisições que o navegador envia, então o edge retorna os dados de cache da página que você já está visualizando.

Para adicionar o cabeçalho:

1. Instale a extensão [ModHeader](https://chrome.google.com/webstore/detail/modheader-modify-http-hea/idgpnmonknjnojddfkpgkljpfnnfcklj?hl=pt-BR) e selecione **Usar no Chrome**.
2. Na barra de ferramentas do Google Chrome, selecione **Extensões** e depois selecione **ModHeader**.
3. Na página **Profile**, selecione **Request headers**.
4. Em **Name**, insira `Pragma`.
5. Em **Value**, insira `azion-debug-cache`.
6. Selecione o ícone **Pause ModHeader**.
7. Selecione o ícone **Resume ModHeader**.

O ModHeader passa a enviar o cabeçalho de debug em todas as requisições.

---

## Leia os indicadores de cache

As Developer Tools mostram os cabeçalhos de resposta de cada requisição da página, incluindo os cabeçalhos de cache que o edge adiciona.

Para ler os indicadores:

1. Na barra de ferramentas do Google Chrome, selecione o botão **Personalize e controle o Google Chrome**, representado pelo ícone ︙.
2. Vá para **Mais ferramentas** > **Ferramentas do desenvolvedor**.
3. Selecione a aba **Network**.
4. Acesse a página cujo conteúdo está em cache.
5. Na lista de requisições, selecione o conteúdo cacheado.
6. Selecione a aba **Headers**.

Os cabeçalhos de resposta listam os indicadores de cache do objeto:

| Campo | Descrição |
| --- | --- |
| X-Cache | Status da requisição, podendo ser HIT, MISS, EXPIRED, UPDATING ou STALE. |
| X-Cache-Key | Chave de cache do objeto. Normalmente utilizada a combinação de host + URI + argumentos. |
| X-Cache-File | Arquivo de cache do objeto, sendo ele composto do md5 da chave de cache. |
| X-Cache-Since | Unix Time Stamp* da entrada do objeto em cache. |
| X-Cache-Expire | Unix Time Stamp* da saída do objeto em cache. |
| X-Cache-Expire-In | Tempo restante do objeto em cache, em segundos. |
| X-Cache-Valid | Tempo configurado para o objeto no cache. Este tempo pode ser configurado incondicionalmente no servidor ou pode vir da origem via cabeçalhos Cache-Control. |
| X-Cache-Config | ID da configuração do virtual host no webserver. Este valor é gerado pelo Azion Console. |
| X-Cache-ID | Identificador único da requisição. |

*\* Você pode converter um Unix Time Stamp em formato humano utilizando [o site Unix Time Stamp](http://www.unixtimestamp.com/).*
